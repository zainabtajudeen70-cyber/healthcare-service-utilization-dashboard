# Healthcare Service Utilization Dashboard

## Project Overview
This project uses Google Looker Studio to visualize healthcare service utilization across three primary healthcare facilities. The dashboard summarizes patient records, visits, healthcare services, gender, and age groups.

## Tools Used
- Google Looker Studio
- Data visualization
- Data analysis and reporting

## Key Performance Indicators
- **Total Patient Records:** 20
- **Total Visits:** 58

## Key Insights
- PHC B recorded the highest number of patient records, with 8.
- PHC A recorded the highest number of visits, with 24.
- General services had the highest number of patient records, with 6.
- Female patients accounted for 14 records, compared with 6 male records.
- The 25–34 age group had the highest number of records, with 9.

## Dashboard Features
- Patient records by healthcare facility
- Total visits by facility
- Patient records by healthcare service
- Patient records by gender
- Patient records by age group
- KPI scorecards

## Project Objective
To demonstrate how healthcare data visualization can summarize service utilization patterns and support evidence-informed planning and decision-making.
